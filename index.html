💾 Backup & Daten

Deine Rezepte werden auf diesem Gerät im Browser gespeichert. Sichere sie gelegentlich als Datei, damit du sie bei einem Geräte- oder Browserwechsel wiederherstellen kannst.

Sicherer Import: Rezepte aus einer Datei werden hinzugefügt, nicht überschrieben. Doppelte Rezeptnamen werden übersprungen. Ein Foto wird im Backup mitgespeichert.
